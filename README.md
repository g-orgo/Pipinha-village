# Pipinha's Village (Minecraft 1.21.1, NeoForge 21.1.265)

A modpack about farming, trading and town life, based on Society: Sunlit Valley.

This is the 1.21.1 edition. It exists because we wanted **Create Aeronautics** in the pack, and it is not available for 1.20.1. It comes with Create Aeronautics, Aeronautics Camera Sync, Create High Seas, Sable, Let it Walk! (walking machines), Create Waystones Integration and FTB Stuff & Things. If you want the 1.20.1 edition, it lives in the [`1.20.1`](https://github.com/g-orgo/Pipinha-village/tree/1.20.1) branch.

## Status

- Mods, configs, recipes, tags and data are already in the 1.21 format, and worlds from the 1.20.1 edition can be converted.
- Quests, shops, villages and the towns generated by Lost Cities are still being brought over from the 1.20.1 edition, so some of them may be missing or incomplete.

## Installation

It takes about 5 minutes. Close the launcher and Minecraft before you start.

1. **Create the profile.** In your launcher (CurseForge, Prism, MultiMC, Modrinth App...), create a profile with **Minecraft 1.21.1** and **NeoForge 21.1.265**.
2. **Download the pack.** On this page, click **Code > Download ZIP**. Do not extract it.
3. **Put it in the profile folder.** Open the profile folder (CurseForge: right-click the profile > **Open Folder**) and put the zip there. Open the zip, go into the `Pipinha-village-main` folder and drag the installer for your system into the profile folder: `install.bat` (Windows) or `install.sh` (Linux).
4. **Install.** Windows: double-click `install.bat`. Linux: open a terminal in the profile folder and run `bash install.sh`.
5. **Play.** Start the profile from the launcher. Give it 8 GB of memory.

The installer replaces the `mods`, `kubejs`, `resourcepacks` and `moonlight-global-datapacks` folders with the pack's and keeps your options. If the profile is not 1.21.1 with NeoForge 21.1.265, it warns you before changing anything.

- **Got a `Modpack.zip`?** Do the same, using it instead of the GitHub zip (the installer is inside it).
- **The installer did not run?** Delete the four folders above from the profile folder and extract the zip contents into it (for the GitHub zip, what is inside `Pipinha-village-main`), replacing anything it asks about.
- **Have a 1.20.1 world?** Only open a copy of the save, and do not mix files from the two editions.
