# Pipinha's Village (Minecraft 1.21.1, NeoForge)

Modpack de fazenda, comércio e vida na cidade, baseado no Society: Sunlit Valley.

Esta branch é a versão 1.21.1 (NeoForge 21.1.265), ainda em migração. A versão jogável hoje é a 1.20.1, na branch `main`. Quando a migração terminar, este repositório passa a ser só da 1.21.1.

## Estado

- Fase 1 pronta: os mods (`mods/`), com as dependências conferidas. Configs, KubeJS, quests e datapacks ainda não foram portados.
- Plano, fases e decisões: `docs/migracao/PLANO.md`.

## Teste (Linux ou Windows)

1. No CurseForge, crie um perfil personalizado: Minecraft 1.21.1, NeoForge 21.1.265.
2. Copie a pasta `mods/` desta branch para a pasta do perfil.
3. Baixe os jars listados em `mods/EXTERNAL.txt` (passam do limite de 100 MB do GitHub) para a mesma pasta `mods/`.
