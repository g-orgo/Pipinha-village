### Pipinha's Village
### 1.21.1 에디션
^^^

이제 마인크래프트 1.21.1에서 만나는 피피냐의 마을에 오신 것을 환영합니다! Society: Sunlit Valley를 기반으로 합니다.

이 버전은 Create Aeronautics를 팩에 넣고 싶었기 때문에 만들어졌습니다. 1.20.1용은 존재하지 않았습니다.

### 새로운 기능
+ Create Aeronautics: 자동차와 배부터 비행기와 비행선까지, 물리 기반 장치 (Simulated, Aeronautics, Offroad)
+ Aeronautics Camera Sync: 탑승한 비행체를 카메라가 따라갑니다
+ Create High Seas: 물리 구조물이 물에 뜨고 내부에 물이 찰 수 있습니다
+ Sable: 물리로 움직이는 블록 구조물
+ 애드온이 업데이트된 Create 6
+ Embeddium + Oculus 대신 Sodium + Iris: 새 버전의 셰이더와 성능

### 변경
+ NeoForge 21.1.265 기반 마인크래프트 1.21.1
+ 일부 단축키 이름이 바뀌었습니다 (ParCool, Refined Storage, Relics, Punchy): 필요하면 조작 설정에서 다시 지정하세요
+ 1.20.1 에디션의 월드는 복사본에서 변환되며, 함께 오지 않은 모드의 블록은 사라집니다

### 제거
- Botania, Splendid Slimes, Create: Splendid Cogs 및 관련 퀘스트, 상점 품목, 레시피
- 1.21.1 버전이 없는 모드 (Species, Re:Deco, Quark Delight, Refined Storage Addons 등)
