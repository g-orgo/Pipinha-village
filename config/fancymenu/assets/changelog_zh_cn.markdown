### Pipinha's Village
### 1.21.1 版
^^^

欢迎来到皮皮尼亚的村庄，现已登陆 Minecraft 1.21.1！基于 Society: Sunlit Valley。

这个版本之所以存在，是因为我们想在整合包中加入 Create Aeronautics，而它没有 1.20.1 版本。

### 新内容
+ Create Aeronautics：基于物理的装置，从汽车、船只到飞机和飞艇（Simulated、Aeronautics 和 Offroad）
+ Aeronautics Camera Sync：镜头跟随你乘坐的飞行器
+ Create High Seas：物理装置可以漂浮在水上，内部也会进水
+ Sable：带物理效果的移动方块结构
+ Create 6 及其更新后的附属模组
+ 使用 Sodium + Iris 代替 Embeddium + Oculus：新版本的光影与性能

### 变更
+ 基于 NeoForge 21.1.265 的 Minecraft 1.21.1
+ 部分按键绑定改了名字（ParCool、Refined Storage、Relics 和 Punchy）：如有需要请在控制设置中重新设置
+ 1.20.1 版的世界需在副本中转换，未随迁的模组方块会消失

### 移除
- Botania、Splendid Slimes 和 Create: Splendid Cogs，以及相关的任务、商品和配方
- 没有 1.21.1 版本的模组，例如 Species、Re:Deco、Quark Delight 和 Refined Storage Addons

### 进行中
+ 1.20.1 版的商店、职业、经济、进食动画、村庄和任务正在逐步迁移

有疑问？打开任务书中的 Welcome 章节，指南都在那里。
